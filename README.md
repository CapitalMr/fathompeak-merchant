# 沐仞商家管理后台

给客户看的账房。当前客户是深州电力，电站选的是河北深州集中式光伏。卡是货，卡上的模型产出 token，绿电按这座电站来对。

视觉沿用 `web-refactor` 控制台：纸色 `#f8f8f8`、晨蓝 `#2f63b8`、峰紫 `#4e3f66`、Fraunces 标题、DM Sans / DM Mono、248px 侧栏、320px 右栏、胶囊导航、发丝分割线。账从 2026-10-01 记到 2026-11-11，按日终入账。

通话里的「木犀」这里写成沐曦曦云 C500，并单独放了一台华为昇腾 910C。

## 打开

在仓库根目录起一个静态服务，字体才能从旁边的 `web-refactor` 读到：

```bash
python3 -m http.server 8756
```

浏览器打开 <http://127.0.0.1:8756/web-merchant/> 。点「登陆」。直接打开 `index.html` 也可以，只要 `web-refactor/public/fonts` 还在上一级。

## 页面

概览。今日入账、比昨日、近七日、本月至今、十四日柱、七台机器。第一句把视频入账占比和 5090 / H200 / PRO 6000 的电量放在一起。

```
┌ 侧栏 ──────┬ 今日入账                                        ┐
│ 概览       │ ¥4,143.19                                     │
│ 我的机器   │ 视频占 70% 入账，只占 8.7% token               │
│ 模型产出   │ [今日] [近七日] [本月至今]                     │
│ 账本       │ 十四日柱                                       │
│  对账      │ 机器表：卡、模型、负载、入账、token、绿电       │
│  绿电      ├ 右栏：本月入账 / 钱包 / 绿电 / 两条占比 ───────┤
│  结算      │                                                │
└────────────┴────────────────────────────────────────────────┘
```

我的机器。一台一张卡片。标题是模型名，下面 8 个卡位，能看见 5090、PRO 6000、PRO 6000D、H100、H200、B300、昇腾 910C、曦云 C500。可按对话 / 视频滤。

模型产出。每台一行算式：百万 token × 实收单价 = 入账。服务费不在单价里。

统计对账。左列按日，右栏是选中那一天的机器凭证。流水 = 入账 + 服务费，服务费 = 入账 × 18/82。

```
┌ 近七日 | 本月 | 全部 ┐
│ 日期  入账  绿电  状态 │  11月11日
│ ...                   │  ¥…… 入账
│ 合计 = 概览同口径      │  七台：百万 token × 单价
└───────────────────────┴────────────────┘
```

绿电账本。公式写在页面上：

```
kWh = Σ 卡数 × 额定 kW × 当日平均负载 × 24
```

5090（575W、Qwen3-32B、负载 46%）和 PRO 6000（600W、DeepSeek-V3、负载 44%）单卡电量几乎一样。H200（700W、Wan2.2-14B、负载 88%）同为 8 张卡，电量大约是 5090 的 2.32 倍。B300 跑 Wan2.2-A14B，额定 1400W、负载 92%，单卡最高。Qwen3-8B 在曦云 C500 上负载 34%，Qwen2.5-72B 在昇腾 910C 上负载 56%。电量不从入账里扣。

结算。已到账 + 钱包 = 账本合计。钱包是 11月2日至今还没进银行的钱；每周三把其中上一周打出。收款账户是招商银行，户名深州电力，账号 7559 **** **** 2618。
